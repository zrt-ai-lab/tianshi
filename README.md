# 天市 · v0.0.3

> 天市垣，三垣之一。
> 古人把天上的市集命名于此，垣内星官有帝座、市楼、车肆、列肆、帛度。
> 这个工作台借它的名字：一个看清市场、也看清自己的地方。

A股个股与市场研究台（DeepSeek Harness 插件）。

---

## 界面

浅色研究台、星垣图标、少量金蓝点缀；正文仿宋，标题和数字用系统无衬线字体。包含加载骨架与进度反馈。

## 它做什么

- **个股全景**：技术 / 资金 / 基本面 / 行业 / 公司 / 消息 / 股吧舆情
- **投研结论**：长周期、基本面、估值、政策行业、市场环境、资金、怎么做、失效条件
- **结合你的成本**：记录持仓后，买卖点按你的成本算（止损 / 止盈 / 保本三价位）
- **三条路径**：短线 / 中线 / 长线，各给条件、进场、止损、目标、赔率
- **做T**：分时 + 五档盘口 + 量能，判断今天适不适合做T
- **涨停归因**：为什么涨停、封板强度、同题材弹性标的分层
- **妖股扫描**（独立视图）：
  - 妖股潜质榜 —— 当前强度（相对大盘超额、抗跌、资金、涨停基因）
  - 跨年妖候选 —— 日历窗口 + 公开资料整理的多项画像特征，逐项 ✓/✗ 与标准值
  - 阶段扫描 —— 埋伏 / 启动 / 一波 / 二波 / 高位风险
- **连板梯队**：分层 + 晋级率（含空间板与断板）
- **交易记录与复盘**：FIFO 配对算真实盈亏，K线标买卖点
- **数据溯源**：每个维度的出处与局限，「来源」页签逐条可查

---

## 数据边界（重要）

- 数据来自腾讯财经 / 东方财富公开接口，**非交易所直连**
- 只有行情价格做双源交叉验证（容差 0.011 元 / 0.05%），其余单源
- 雪球、同花顺、大V观点**未接入**（已实测抓不到）
- **不做涨跌预测**：方向预测实测命中率低于随机（短线 38.0%、中线 41.5%、长线 45.9%）；这些为早期有限样本结果，非本版本收益承诺
- 妖股潜质分是**形态相似度**，不是概率；跨年画像特征是历史统计的**共同点**，不是充分条件
- 记录主要存本机；点击AI分析会将行情、持仓成本等上下文发送给所配置的模型服务，详见 [PRIVACY.md](PRIVACY.md)

## 从 GitHub 安装

推荐安装固定版本的 Release 包：

```bash
dsh plugin --profile desktop add https://github.com/zrt-ai-lab/tianshi/releases/download/v0.0.3/dsh-tianshi-0.0.3.tgz
```

macOS 没有配置 `dsh` 命令时：

```bash
"/Applications/DeepSeek Harness.app/Contents/Resources/runtime/cli/bin/dsh" \
  plugin --profile desktop add https://github.com/zrt-ai-lab/tianshi/releases/download/v0.0.3/dsh-tianshi-0.0.3.tgz
```

也可直接安装固定 Git 标签：

```bash
dsh plugin --profile desktop add github:zrt-ai-lab/tianshi#v0.0.3
```

安装后完全退出 Harness 再打开。profile 示例为 desktop，请以实际使用配置为准。AI分析沿用安装者自己的模型和额度。

ETF观察不附带开发者的分享码，需自行配置。记录主要保存在浏览器localStorage，应用端口改变可能导致旧记录不可见，当前没有自动迁移。项目为早期研究工具，妖股评分未经过样本外有效性验证，不承诺准确率或收益。

详见 [INSTALL.md](INSTALL.md) 和 [PRIVACY.md](PRIVACY.md)。

## 开发

本仓库是自包含的干净发布树：`lib/` 为插件入口和界面，`core/` 为分析模块。没有开发仓历史、个人持仓、证据快照或凭据。可在仓库根目录执行 `npm pack` 构建安装包，不需要从其他目录复制分析引擎。
